# 🌍 GeoPulse — Interactive Geography Guessing Game

An interactive, high-precision geography guessing game built with **React**, **Leaflet**, and **Vite**. Players test their geographic intuition by analyzing clues and placing pins on an interactive map across India and global landmarks.

🎮 **Live Demo:** [Play GeoPulse Live](https://geolocate-india.vercel.app)

---

## ✨ Features

* **🇮🇳 India Mode:** Guess iconic historical landmarks, natural wonders, and cultural hubs across India (Taj Mahal, Pangong Tso, Varanasi Ghats, Meenakshi Temple, and more).
* **🌍 World Wonders Mode:** Test your global knowledge across international wonders (Eiffel Tower, Colosseum, Giza Pyramids, Mount Fuji, and more).
* **🗺️ Interactive Map:** Powered by Leaflet and OpenStreetMap tiles with smooth zoom, panning, and pin drops.
* **📐 Haversine Distance Calculation:** Accurate mathematical distance calculation between player pins and true coordinates.
* **🔥 Dynamic Scoring & Streaks:** Scaled point system (up to 5,000 pts per round) with streak multipliers and celebratory animations.
* **🔊 Sound FX & Animations:** Audio beeps and fanfare synthesized via the Web Audio API with confetti celebration effects.
* **📱 Responsive Design:** Sleek, modern dark-mode interface optimized for desktop and mobile screens.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React 18
* **Build Tool:** Vite
* **Maps & Geo-visuals:** Leaflet, React-Leaflet
* **Styling:** Modern CSS3 / Tailwind Utility Architecture
* **Effects & Audio:** Canvas Confetti, Web Audio API
* **Deployment & CI/CD:** Vercel
